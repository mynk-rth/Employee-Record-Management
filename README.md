# Employee Record Management System

A simple **Employee Record Management System** built using **C programming and file handling**.

## Features

* Add employee records
* Display employee records
* Search employee records
* Edit employee records
* Delete employee records
* Store records using file handling

## Technologies Used

* C
* File Handling
* Structures

## How to Run

Compile the `.c` files using a C compiler and run `Merge.c` to access the main menu.
